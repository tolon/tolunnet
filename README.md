# tolunnet

> An open-source, high-performance TCP/IP stack and `bsdsocket.library` v4.1 runtime for classic Commodore AmigaOS (68k), built on a pinned, hardened copy of [lwIP 2.2.0](https://savannah.nongnu.org/projects/lwip/) running as a dedicated AmigaOS Exec task (`NO_SYS=1`).

---

## Overview & Motivation

Classic AmigaOS has long lacked an actively maintained, production-grade, 100% open-source TCP/IP stack. Roadshow is proprietary commercial software. Miami and Miami Deluxe are discontinued abandonware. AmiTCP's last open-source release dates back to version 3.0b in 1994.

**tolunnet** bridges this gap: modern, fully documented, rigorously verified, and distributed under the **GNU General Public License v3.0 (GPL-3.0-or-later)**. It provides a drop-in replacement `bsdsocket.library` for classic 68k Amiga systems (from a bone-stock Amiga 500 up to accelerated Amiga 4000 and PiStorm systems), complete with standard network diagnostic tools, a modern Setup wizard, and Workbench Preferences.

- **Author:** İsmail Öztürk

> **Compatibility Notice:** Applications communicate with tolunnet strictly via the standard AmigaOS library interface: `OpenLibrary("bsdsocket.library", 4)`. Calling `bsdsocket.library` functions from any third-party application (freeware, shareware, or commercial) does **not** subject that application to the GPL.

## Key Architecture & Features

<!-- lvo-stats:start -->
- **`bsdsocket.library` v4.1 runtime:** 139 total LVO slots (-30 … -858; 121 SFD functions + reserved) generated from Roadshow SDK `sfd/bsdsocket_lib.sfd` via `scripts/gen_lvo_table.py`; **70 BUILT** (vector → IPC → daemon handler, or handled in-library), 51 honest stubs returning exact Roadshow error semantics (`ENOSYS`, `ENXIO`, `NULL`, `NO_RECOVERY`, `FALSE`), 0 BROKEN (marshaled without a daemon handler). Vector-by-vector status and bench PASS coverage: [`src/lib/lib_compat_table.gen.md`](src/lib/lib_compat_table.gen.md) (single source of truth, regenerated by `make python-checks`).
<!-- lvo-stats:end -->
- **Roadshow 1.8 & AmiTCP V4 Standard API:** Comprehensive implementation of socket primitives: `SocketBaseTagList` (-294), `bind`, `listen`, `accept`, `connect`, `shutdown`, `getsockname`, `getpeername`, `WaitSelect` (timer-driven with SIGIO delivery), `getservbyname`/`byport`, `getprotobyname`/`bynumber`, `getnetbyname`/`byaddr`, `inet_aton`, `inet_ntop`, `inet_pton`, `Inet_LnaOf`, `Inet_NetOf`, `Inet_MakeAddr`, `inet_network`, `gethostname`, `gethostid`, `gethostbyname_r`, `gethostbyaddr_r`, `vsyslog`, and `Dup2Socket`.
- **Zero-Allocation Exec IPC:** High-speed message passing between client applications and the network daemon using native AmigaOS Exec `PutMsg`/`WaitPort`/`ReplyMsg` queues with zero per-packet allocation overhead and `MEMF_PUBLIC` one-shot query safety.
- **Universal Motorola 68k Code (`-m68000 -msoft-float`):** A single binary set runs on all Motorola 68000, 68010, 68020, 68030, 68040, and 68060 processors without requiring a Floating Point Unit (FPU). Shipped binaries contain no 68020+ instructions.
- **Motorola 68000 Alignment & Guru Defense:** Strict 4-byte memory pool alignment and `ETH_PAD_SIZE 2` framing guarantee that all IP/TCP header accesses land on 4-byte boundaries, preventing fatal 68000 `#80000003` Address Error Gurus.
- **SANA-II Rev 7 Network Driver Interface:** Standard register convention trampolines (`A0`/`A1`/`D0`) with BufferManagement, multi-request DMA read pumps, and support for all standard SANA-II Ethernet/Wireless drivers (`a2065.device`, `ethernet.device`, `wifipi.device`, `cnet.device`, `ariadne.device`, etc.).
- **Hardware-Seeded Entropy:** Cryptographically hardened Pseudo-Random Number Generator (PRNG) pool seeded at boot from `GetSysTime` (microsecond resolution), network hardware MAC address, and memory allocator pool addresses.
- **Unified Text Configuration:** `DEVS:tolunnet.config` (`KEY=VALUE`) provides a persistent, human-editable source of truth (`DEVICE`, `UNIT`, `DHCP`, `IP`, `NETMASK`, `GATEWAY`, `DNS`, `DNS2`, `HOSTNAME`, `MTU`, `DEBUG`, `TX_QUEUE`) with dynamic file modification detection.
- **`usergroup.library` Universal Runtime:** Full-featured 43-vector resident Amiga shared library (`LIBS:usergroup.library`) for user/group identity, credential management (`getuid`, `geteuid`, `getpwuid`, `getpwnam`, `getgrnam`, `getgroups`), and traditional crypt/salt routines. Provides an in-memory database with standard default accounts (`root`, `amiga`, `nobody`) and disk fallback (`DEVS:passwd`), fully compliant with Roadshow and AmiSSL requirements.
- **AutoIP (RFC 3927 Link-Local Fallback):** Automatic link-local IPv4 allocation (`169.254.x.x` / `255.255.0.0`) with Address Conflict Detection (ACD) and fast 3–4 second DHCP cooperation. Operates seamlessly in ad-hoc direct crossover and unmanaged switch environments.
- **Zeroconf / mDNS Responder & LAN Discovery:** RFC 6762 multicast DNS responder answering queries for `<hostname>.local` on UDP port 5353 (`224.0.0.251`). Publishes `_workstation._tcp` DNS-SD service with hardware/OS metadata (`model=Amiga`, `os=AmigaOS`, `stack=tolunnet`), making the Amiga immediately discoverable and visible in modern network browsers (macOS Finder, Windows Network Explorer, Linux Avahi).
- **Metric-Driven Workbench GUI:**
  - `TolunnetSetup`: Metric-driven wizard that automatically scales to NTSC (640×200), PAL (640×256), and RTG high-resolution displays (Picasso96/uaegfx 800×600, 1024×768, 1920×1080) based on font metrics (`TextLength()`, `Font->tf_YSize`).
  - `TolunnetPrefs`: Full-featured Workbench Preferences tool with non-blocking Start/Stop daemon controls, ToolTypes (`TOOLPRI`, `PUBSCREEN`), and WBStartup support.

## Testing Process & Verification Methodology

The stability of an AmigaOS network stack is paramount: on an operating system without memory protection or virtual address translation, a single unaligned access, memory corruption, or race condition results in a fatal Guru Meditation (`#80000003` or `#80000004`). 

To eliminate these failure classes, **tolunnet** is subjected to a multi-tiered, automated verification pipeline:

### 1. Host Unit Test Suite (Native & Sanitized)
Before touching any 68k emulator or real hardware, 20 standalone test suites are compiled with GCC/Clang on the development host under AddressSanitizer (ASan) and UndefinedBehaviorSanitizer (UBSan):
- `test_inet_addr` — IP address parsing and format conversion.
- `test_config` — Text configuration parser, key validation, and default fallback.
- `test_usergroup` — POSIX user and group database, context credentials, and crypt routines.
- `test_sbtc` — TagList validation across all 69 Roadshow/AmiTCP tags.
- `test_fdset` — Descriptor set bitmask operations and bounds checking.
- `test_lvo_table` — Complete 139-vector SFD jump table offset and signature verification.
- `test_route` — Route table lookup, default gateway routing, and mask matching.
- `test_http` — HTTP URL parsing, chunked transfer decoding, and Range header formatting.
- `test_icmp` — ICMP checksumming and packet serialization.
- `test_sockopt` — Socket option validation, getsockopt length checking, and error reporting.

### 2. Dual-Cycle Headless Conformance Verification
An automated WinUAE testing harness runs comprehensive dual-cycle conformance sweeps across two distinct hardware targets:
1. **Amiga 1200 Profile:** Motorola 68EC020, AGA chipset, PAL 640×256.
2. **Amiga 600 / 500 Profile:** Motorola 68000 (cycle-exact, 7.09 MHz), ECS chipset, NTSC 640×200.

**The Dual-Cycle Protocol:**
- **Cycle 1 (Cold Start):** The daemon starts from a pristine Workbench 3.0 disk image, opens the SANA-II device, negotiates a DHCP lease (`10.0.2.15`), exercises all socket operations (TCP stream, UDP datagram, RAW ICMP, non-blocking `WaitSelect`, descriptor inheritance), calls all 139 SFD library vectors without error, and performs a clean shutdown.
- **Cycle 2 (Warm Relaunch):** Immediately without rebooting AmigaOS, the daemon re-opens the SANA-II driver (verifying `S2ERR_BAD_STATE` / `S2WERR_IS_CONFIGURED` tolerance), acquires a fresh lease, recreates socket tables, and executes a second complete pass.
- **MuForce / Enforcer Gate:** Verifies zero unaligned accesses and zero illegal memory reads across all operations.

### 3. Session-Profile Soak Testing (2-Hour Reliability Harness)
Unlike modern servers that prioritize uninterrupted months of uptime, hobbyist Amiga systems are typically booted and used for a few hours per evening. The critical failure mode is "session drift": repeated launches, socket allocations, driver re-opens, and application shutdowns leaving residual memory or dangling interrupts.

The **Session-Profile Soak Test** (`ci/bench.sh soak`) models this real-world usage over a continuous 2-hour window:
- **12 Consecutive Sessions:** 12 independent 10-minute operational cycles.
- **Continuous High-Frequency Traffic:** Inside every 10-minute window, non-stop `ping` bursts, HTTP `wget` downloads, and live telemetry capture exercise the stack continuously.
- **Orderly Teardown & Restart:** At the conclusion of every 10-minute cycle, `TolunnetControl STOP` terminates the stack, tears down SANA-II queues, unloads the library, takes an Exec memory snapshot (`Avail`), and `TolunnetControl START` launches a fresh daemon instance.
- **Success Criteria:**
  - Zero Guru Meditations or system freezes.
  - Zero packet drops or protocol errors.
  - **Chip RAM Drift:** Strictly **0 bytes** leaked across all 12 cycles.
  - **Fast RAM Drift:** Total memory delta across 2 hours of heavy traffic and 12 daemon restarts must not exceed **8 KB** (typically < 1 KB in practice).
  - 12/12 verified fresh lwIP re-initializations.

### 4. Real-Hardware & Accelerator Verification
In addition to emulation, tolunnet is verified on real classic hardware:
- **Target Setup:** Amiga 500 + PiStorm accelerator + Raspberry Pi 3A+/4.
- **Network Interface:** `wifipi.device` (high-speed wireless SANA-II driver).
- **Display Modes:** Standard 15 kHz OCS/ECS/AGA screens and 16-bit/24-bit RTG screen modes (Picasso96).

## Building from Source

Cross-compilation is performed using `m68k-amigaos-gcc` on Linux or Windows WSL (Ubuntu):

```bash
# Clone the repository
git clone https://github.com/tolon/tolunnet.git
cd tolunnet

# Build all binaries, the LhA release archive, and the ADF disk image:
make package CROSS=/home/tolon/opt/m68k-amigaos/bin/m68k-amigaos-

# Run host unit tests under AddressSanitizer:
make test-host

# Verify code alignment and 68000 instruction compliance:
make align-check
make asm-check
```

Build outputs are placed in `build/`:
- `build/tolunnet-1.2.0-rc3.lha` — Standard Amiga LhA archive containing binaries, icons, documentation, and the installer script.
- `build/tolunnet.adf` — Standard 880 KB Amiga floppy disk image containing stripped binaries for floppy-only setups.

## Installation

### Automatic Installation (Recommended)
1. Extract `tolunnet-1.2.0-rc3.lha` to `RAM:` or a temporary drawer.
2. Double-click **`Install_Tolunnet`**.
3. The Commodore Installer script will guide you through:
   - Selecting your network card driver (`SANA-II` device in `DEVS:Networks/`).
   - Choosing DHCP auto-configuration or static IP settings.
   - Adding tolunnet to `S:User-Startup` or `WBStartup`.
4. Run `TolunnetSetup` from the system drawer to verify connectivity.

### Manual Installation
1. Copy the contents of `C/` to `SYS:C/`.
2. Copy `TolunnetPrefs` and `TolunnetSetup` to `SYS:Prefs/`.
3. Copy `DEVS/tolunnet.config` to `DEVS:tolunnet.config` and edit as needed:
   ```ini
   DEVICE=ethernet.device
   UNIT=0
   DHCP=YES
   DNS=1.1.1.1
   LOG=NIL:
   ```
4. Start the stack in `S:User-Startup`:
   ```amiga
   Run >NIL: C:tolunnet
   ```
