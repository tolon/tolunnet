# Gotek release set (11aa item 2). No size heuristic: every member of
# the package tree MUST appear exactly once with disk 1 or disk 2;
# scripts/build_adf.py fails the build on unassigned paths, duplicate
# assignments or a disk that does not fit. Paths are relative to the
# package tree root (the drawer the LHA extracts).

# the Commodore Installer binary (both copies), the docs and C/tolunnet
# plus the smallest C/ commands. disk 2 carries the rest, including
# TolunnetSetup, TolunnetPrefs and Libs/usergroup.library.
