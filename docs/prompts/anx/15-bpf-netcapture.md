# ANX-15 — BPF (`bpf_*` vektörleri) + `NetCapture` (tcpdump benzeri)
Kurallar (değişmez): (1) yalnız bu dosyadaki iş; başka dosyaya, başka TNET'e dokunma. (2) Tek commit; iş bitmeden ara commit yok, iş bittikten sonra bekleyen değişiklik yok. (3) Kanıt = `ci/bench.sh` log dizini + host test çıktısı; kendi ifaden kanıt değildir. (4) DUR kuralı: bench üst üste 2 kez kırmızı → dur; 4 saat içinde commit yoksa → dur; durunca `STOP-REPORT.md` yaz (ne yapıldı, ne kırmızı, son yeşil commit) ve bitir. (5) Yeşil kalması gereken taban: mevcut core testleri iki profilde (a1200, 68000) — biri düşerse bu iş kırmızıdır. ANX-14 önkoşul. Referans: AmiNetXDuo `src/bpf/{bpf_filter.c,bpf_validate.c,bpf_channel.c,bpf_tap.c,bpf_tap_tx.c}` (`bpf_filter.c` klasik BSD yorumlayıcı — doğrudan alınabilir), `src/tools/netcapture.c`, Roadshow SDK `netinclude/net/bpf.h` (`BIOC*` ioctl'ler, `struct bpf_hdr`, `BPF_MAXINSNS 512`, `BPF_MAXBUFSIZE 0x8000`).
1. Vektörler SFD'den: `bpf_open/close/read/write/set_notify/set_interface/set_read_timeout/set_buffer_len/set_promiscuous/get_stats/...` (adları ve ofsetleri `sfd/bsdsocket_lib.sfd`'den; değerleri dosyadan al). Kanal = `struct TnBpfChannel` (filtre programı, halka tampon `blen`, `MsgPort` bildirim, `promisc`, `timeout`).
2. Tap noktası: daemon'da `netif->input` ve `netif->linkoutput` sarmalayıcıları; her kanal için filtre çalıştır, eşleşeni `bpf_hdr` + timestamp (`GetSysTime`) ile halkaya kopyala. **`Forbid` içinde filtre çalıştırma** (AmiNetXDuo `FORBID.md`'de en uzun Forbid bölgesi olarak kendisi yazıyor): halkayı `ObtainSemaphore` ile koru, filtre semafor dışında; `Disable` yok. ANX-03 kapısı geçmeli.
3. `bpf_validate`: yükleme öncesi programı doğrula (geri sıçrama yok, `BPF_MAXINSNS`, bölme sıfır sabiti, bellek indeks sınırı) — doğrulanmamış program çalıştırılmaz.
4. `C:NetCapture` (`src/cmds/`): `IFACE/K,FILTER/K,COUNT/N,SNAPLEN/N,WRITE/K` (pcap dosyası, `libpcap` 2.4 başlığı, magic `0xa1b2c3d4`), ekrana özet satır; `tcpdump -r` ile açılabilirlik host testi (`tests/host/test_pcap_writer.c`).
5. Bench `tc_bpf`: loopback'e 10 UDP paket, filtre `udp and port 7777`, halkada 10 kayıt; promisc kapalı/açık `S2_CONFIGINTERFACE` çağrısı sayısı.
Kabul: host+bench yeşil, `SBTC_HAVE_MONITORING_API`? — yalnızca gerçekten sağlanan alt API için TRUE, commit `bpf: packet filter channels + NetCapture`.
