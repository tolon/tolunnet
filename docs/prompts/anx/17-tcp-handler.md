# ANX-17 — `TCP:` DOS handler (`TCP:host/port` dosyaları)
Kurallar (değişmez): (1) yalnız bu dosyadaki iş; başka dosyaya, başka TNET'e dokunma. (2) Tek commit; iş bitmeden ara commit yok, iş bittikten sonra bekleyen değişiklik yok. (3) Kanıt = `ci/bench.sh` log dizini + host test çıktısı; kendi ifaden kanıt değildir. (4) DUR kuralı: bench üst üste 2 kez kırmızı → dur; 4 saat içinde commit yoksa → dur; durunca `STOP-REPORT.md` yaz (ne yapıldı, ne kırmızı, son yeşil commit) ve bitir. (5) Yeşil kalması gereken taban: mevcut core testleri iki profilde (a1200, 68000) — biri düşerse bu iş kırmızıdır. Referans: AmiNetXDuo `src/bsdsocket/tcp_handler.c`, AmiTCP `TCP:` ve Roadshow `L:tcp-handler` davranışı.
1. `src/handler/tcp_handler.c` → `L:tcp-handler`; `DEVS:DOSDrivers/TCP` (`Handler = L:tcp-handler`, `StackSize = 8192`, `Priority = 5`, `GlobVec = -1`, `Startup = ""`), `.info` dahil. Handler `DosPacket` döngüsü: `ACTION_FINDINPUT/FINDOUTPUT/FINDUPDATE` → yolu `host/port[/tag]` ayrıştır (`port` sayı ya da `getservbyname`), kendi `SocketBase`'ini `OpenLibrary("bsdsocket.library",4)` ile **açan handler task'ı** (per-opener klon zaten var); `connect`; `ACTION_READ/WRITE` → `recv/send`; `ACTION_END` → `CloseSocket`; `ACTION_IS_FILESYSTEM` FALSE; `ACTION_SEEK` hata `ERROR_ACTION_NOT_KNOWN`.
2. Dinleme: `TCP:port` (host boş) → `bind+listen+accept` tek bağlantı (AmiTCP semantiği); `Open` accept'te bloklar; Ctrl-C (`SIGBREAKF_CTRL_C` handler görevine) iptal.
3. Ağ yokken (daemon kapalı): `Open` `ERROR_DEVICE_NOT_MOUNTED` yerine `ERROR_OBJECT_NOT_FOUND` + `tn_logf`; requester yok (`pr_WindowPtr=-1` handler'da).
4. Bench `tc_tcp_handler`: `Echo >TCP:10.0.2.2/80 "GET / HTTP/1.0*N*N"` + `Type TCP:...` yerine tek betik: `Copy TCP:10.0.2.2/80 TO RAM:x` (slirp HTTP yoksa loopback `tc_listen` sunucusuna); dosya boyutu > 0.
5. Installer: `DEVS:DOSDrivers/TCP` ve `L:tcp-handler` kur; Roadshow'un `tcp-handler`'ı varsa **üstüne yazma**, `TolunnetTCP` adıyla `Storage/DOSDrivers`'a koy ve söyle.
Kabul: bench yeşil (+1), commit `handler: TCP: DOS handler`.
