# ANX-22 — CPU'ya göre asm checksum/memcpy (`AttnFlags` dispatch), tek binary
Kurallar (değişmez): (1) yalnız bu dosyadaki iş; başka dosyaya, başka TNET'e dokunma. (2) Tek commit; iş bitmeden ara commit yok, iş bittikten sonra bekleyen değişiklik yok. (3) Kanıt = `ci/bench.sh` log dizini + host test çıktısı; kendi ifaden kanıt değildir. (4) DUR kuralı: bench üst üste 2 kez kırmızı → dur; 4 saat içinde commit yoksa → dur; durunca `STOP-REPORT.md` yaz (ne yapıldı, ne kırmızı, son yeşil commit) ve bitir. (5) Yeşil kalması gereken taban: mevcut core testleri iki profilde (a1200, 68000) — biri düşerse bu iş kırmızıdır. Referans: AmiNetXDuo `src/net68k/` (`.S.in` şablonundan CPU başına `.S` üretimi, çalışma anında `SysBase->AttnFlags` ile işaretçi seçimi). lwIP kancası: `LWIP_CHKSUM` makrosu (`lwipopts.h`) ve `LWIP_CHKSUM_COPY`, `MEMCPY`/`SMEMCPY`.
1. `src/net68k/chksum.S.in` → `scripts/gen_net68k.py` üç varyant üretir: `chksum_000` (16-bit `add.w`/`addx.w`, hizasız veri için bayt yolu), `chksum_020` (32-bit `add.l`/`addx.l`, 4 katlı açık döngü), `chksum_060` (`move16`? hayır — yalnız döngü açma + `addx.l` 8 katlı; 060'ta yavaş komutlardan kaçın: `movem` ok, `dbra` ok). Aynı şablondan `memcpy_000/020` (`move.l` blok, `movem.l` 32 byte/iter, hizalama ön/son kuyruk).
2. `src/net68k/dispatch.c`: `tn_chksum` ve `tn_memcpy` fonksiyon işaretçileri; daemon başlangıcında `AttnFlags & AFF_68060 → 060`, `AFF_68020 → 020`, aksi `000`; `tolunnet STATUS` "cpu=68030 chksum=020" satırı; config `CPU_OVERRIDE=000|020|060` (test için).
3. `lwipopts.h`: `#define LWIP_CHKSUM tn_chksum`, `LWIP_CHKSUM_COPY tn_chksum_copy`, `MEMCPY tn_memcpy`; `CHECKSUM_GEN_*`/`CHECKSUM_CHECK_*` açık kalır.
4. Host testi `tests/host/test_chksum.c`: C referans (`lwip_standard_chksum`) ile 10.000 rastgele tampon (uzunluk 0–4096, ofset 0–3, tek/çift) üç varyant için — asm host'ta çalışmaz; bu yüzden **Amiga bench testi** `tc_chksum_vectors` aynı vektörleri (`tests/vectors/chksum.bin`, host'ta üretilir) üç varyantla çalıştırır ve C referansıyla karşılaştırır; a1200'de `CPU_OVERRIDE` ile 000 ve 020 ikisi de.
5. Ölçüm: `tc_iperf_loopback` (ANX-18) önce/sonra throughput `SUMMARY.txt`'e; kazanç yoksa geri al.
Kabul: `objdump` taraması: `_000` kodunda 020+ opcode yok (TNET-074 script'i varyant başına), bench yeşil, commit `perf: per-CPU asm checksum/memcpy with AttnFlags dispatch`.
