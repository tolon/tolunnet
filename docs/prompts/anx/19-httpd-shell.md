1. `C:tolunnet-httpd` (`PORT/N=8080,ROOT/K,SHELL/S,BIND/K,PASSWORD/K`): tek task, `WaitSelect` ile çoklu bağlantı (≤4), HTTP/1.1 keep-alive yok (basitlik), statik dosyalar `ROOT` (varsayılan `DEVS:tolunnet/www/`), `/status` JSON (`GETSTATUS`/`GETSTATS` IPC'den; ANX-04 sağlık sayaçları dahil), `/shell` (yalnız `SHELL/S` ile) → WebSocket (RFC 6455, `httpws.c` + `httpsha1.c`) ↔ `CON:` yerine `PIPE:` üzerinden `Execute` çıktı/girdi köprüsü (`httpterm.c` mantığı).
2. Güvenlik varsayılanları (config anahtarları, hiçbiri sabit değil): `HTTPD_BIND=` boşsa yalnız ilk arayüzün adresi ve **RFC 1918 istemciler** (`httplock.c` benzeri: uzak adres özel aralıkta değilse 403); `HTTPD_PASSWORD=` boşsa `/shell` kapalı (403 + log). HTTP Basic auth (base64; TLS yok — bunu README'de açık yaz: "LAN içi kullanım"). Yol normalizasyonu `httppath.c` (`..`, `:` kök kaçışı, `//`) + host testi `test_httppath.c` (fuzz girdileri).
3. `www/index.html`: durum sayfası (fetch `/status` 2 s'de bir), 68000'de sunucu yükü düşük kalsın: JSON ≤ 2 KB, dosya gönderimi 1460'lık parçalar `tcp_sndbuf`'a göre.

5. Bench `tc_httpd`: `TolunnetGet http://127.0.0.1:8080/status` JSON ayrıştır, `/shell` parolasız 403, parolalı `echo hello` dönüşü.
