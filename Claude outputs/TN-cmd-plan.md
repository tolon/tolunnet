# tolunnet — Command Suite plan (CMD-1…CMD-6). One step file per group; this file is the map. Rules: one commit per command, `ReadArgs` template + `?` help + RC 0/5/10/20 + Ctrl-C, thin client (no lwIP linked), every tunable a config key, conformance `tc_cmd_<name>` per command (bench, `core`), README.guide entry generated from the template. STOP RULES unchanged.

Shared first (CMD-0, one commit): `src/cmds/cmdlib.c/.h` — `ReadArgs` wrapper, `tn_cmd_rc()`, `tn_cmd_resolve(host)` (numeric or DNS, prints "Resolving…"), `tn_cmd_progress()`, Ctrl-C → `SIGBREAKF_CTRL_C` → clean `CloseSocket`, output via `FPuts`/`VFPrintf` (never stdio). All commands below link only `cmdlib` + `bsdsocket.library`.

CMD-1 (easy): `hostname [NAME] [SAVE/S]` · `sntp HOST [SET/S] [OFFSET/N]` (lwIP `LWIP_SNTP` in daemon, IPC `SNTP_QUERY`; `SET` writes `battclock.resource` + `timer.device`) · `whois QUERY [SERVER]` (TCP 43) · `rdate` dropped (sntp covers) · `TolunnetControl` (renamed CLI front: `START STOP STATUS STATS RECONFIG DIAG RESTART`; keep `tolunnet <subcmd>` as alias).
CMD-2 (DNS/route): `host NAME|ADDR [TYPE=A|PTR|MX|TXT|CNAME] [SERVER]` (own UDP-53 query builder, A/PTR via library, others parsed in the tool) · `nslookup` = alias binary · `arp [SHOW/S] [DELETE ADDR] [ADD ADDR MAC]` (new IPC `ENUMARP`/`ARPCTL`) · `route [SHOW/S] [ADD DEST MASK GW] [DELETE DEST]` (default-gw only until multi-netif; new IPC `ROUTECTL`) · `AddNetRoute`/`DeleteNetRoute` = Roadshow-syntax wrappers over `route`.
CMD-3 (probe): `traceroute HOST [MAXHOPS/N] [QUERIES/N] [WAIT/N] [ICMP/S|UDP/S]` (raw ICMP + `IP_TTL`) · `nc HOST PORT [UDP/S] [LISTEN/S] [ZERO/S] [PORTRANGE]` (stdin/stdout pipe, `WaitSelect` on socket + `CON:` handle) · `iperf` = ship existing `TcpPerf` as `iperf [SERVER/S] [CLIENT HOST] [SECONDS/N]`.
CMD-4 (interactive): `telnet HOST [PORT/N]` (NVT: DO/DONT/WILL/WONT, ECHO/SGA/NAWS/TTYPE=ansi; raw `CON:` with `RAW:`), `tftp HOST [GET|PUT] FILE` (UDP 69, octet mode, block wrap).
CMD-5 (ftp): `ftp [HOST] [PORT/N] [USER] [PASS] [PASSIVE/S] [SCRIPT file]` — interactive commands `open close user ls dir cd lcd get put mget mput bin asc pasv hash prompt quit`; active+passive; `SCRIPT` batch mode for Aminet mirrors; resume via `REST` if server supports.
CMD-6 (Roadshow/AmiNetXDuo parity, scripts): `AddNetInterface NAME [DEVICE] [UNIT/N] [DHCP/S] [ADDRESS] [NETMASK] [GATEWAY]` (Roadshow argument syntax; reads `DEVS:Internet/interfaces` when no args) · `ConfigureNetInterface NAME [UP/S|DOWN/S|DHCP/S|ADDRESS…]` · `Online`/`Offline` = aliases · `ShowNetStatus [INTERFACES/S] [ROUTES/S] [DNS/S] [SOCKETS/S]` · `GetNetStatus [ONLINE/S|ADDRESS/S|DNS/S]` (RC-only for scripts) · `CheckNetConfig` (validates `DEVS:tolunnet.config` + `DEVS:Internet/*`, RC) · `NetShutdown` = `TolunnetControl STOP` · `NetTrace FILE [FILTER] [SNAPLEN/N]` (pcap; needs bpf tap — Scope v4 T4; do last).

Order: CMD-0 → 1 → 2 → 3 → 6 (without NetTrace) → 4 → 5 → NetTrace. `fetch` = alias of `wget` (HTTPS via AmiSSL when present — separate step later). Each group ends with bench green, README.guide + `docs/commands.md` regenerated, `make package`.
