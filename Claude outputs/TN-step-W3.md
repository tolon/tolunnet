# tolunnet — step W3: security/robustness fixes from review of 3e49386 (do before anything else). ISSUES rows TNET-099…105, host test per item, clean bench (dirty: NO) at the end — TNET-098 currently cites only `-dirty` logs; re-run on HEAD and relink.

1. **S:User-Startup edit can destroy the file** (`src/setup/stack_detect.c` ~352-390): edits line-by-line with `char line[512]` (a >511-char line is split into two — the tail becomes a new shell command) and reopens the *same* file `MODE_NEWFILE` before the new content is fully written (disk full/reset → empty User-Startup, no boot network). Fix: read whole file into `AllocVec` (size via `ExamineFH`/`fib_Size`), transform in memory (lines of any length, CR/LF preserved), write to `S:User-Startup.tolunnet-new`, `Rename` over the original only after `Close` succeeds; backup logic unchanged. Same for every other file the wizard rewrites. Host test: 600-char line, missing trailing newline, empty file, CRLF file → byte-identical except the commented lines.
2. **Wireless.prefs injection** (`src/setup/wifi_mgr.c` `tn_format_wireless_block`): SSID/passphrase are pasted into the wpa_supplicant block unescaped — a `"` or newline breaks the file or injects keys. Fix: if SSID contains anything outside `[A-Za-z0-9 ._-]` emit hex form `ssid=<hex>` (no quotes; wpa_supplicant standard); reject passphrase with `"`/control chars (length 8–63 enforced); host test with `"` and `\n` inside both.
3. **SSID read from the wrong tag** (`wifi_mgr.c:130-134`: `S2INFO_BSSID` pointer +8 → SSID). Use `S2INFO_SSID` (addendum §D.2) with its length; BSSID stays 6 bytes. Signal % must come from `S2INFO_Signal` (dBm → % mapping documented). Result: scan list shows real SSIDs; conformance `tc_wifi_scan_parse` with a fake tag list.
4. **Command injection / truncation into `SystemTags`** (`wifi_mgr.c:209-218`, `cmd[128]`): device name comes from a directory listing; validate `[A-Za-z0-9._-]+` and bound to 31 chars; build with a size check (`snprintf` return ≥ size → error), never run a truncated command. Same audit for every `Execute`/`SystemTags` in `src/setup/` and `src/cmds/`.
5. **Passphrase hygiene**: string gadget for the passphrase must not echo by default (draw `*` via `GTST_EditHook` or a custom render; "Show" checkbox); zero the buffer (`memset` + volatile) after writing prefs; never log it (grep `tn_logf` in `wifi_mgr.c`/`TolunnetSetup.c`).
6. **`WORK:tolunnet-task.log` hard-coded in the release daemon** (`src/task/daemon_main.c:143`): on a real Amiga with no `WORK:` volume this raises a *"Please insert volume WORK"* system requester at boot. Remove; log file only from `LOG=` config key; wrap the `Open` in `pr_WindowPtr = (APTR)-1` so a bad path never pops a requester; bench config sets `LOG=WORK:tolunnet-task.log`.
7. **Bench proof**: `ci/bench.sh` must refuse to write ISSUES-citable logs from a dirty tree (exit 2 unless `ALLOW_DIRTY=1`, and then the dir name keeps `-dirty`). Re-run clean for 3e49386+fixes.
