# tolunnet — step W4: TolunnetSetup UI v2 (after step R is green). One commit. ISSUES TNET-110. Reference mockup: `docs/design/wizard-v2.html` (copy the file there). STOP RULES: bench red twice or 3 h without commit → STOP-REPORT.md.

Layout (GadTools, screen font, derived from `scr->Font`; all pixel values below are for topaz/8 and scale by `ta_YSize/8`):
- Window: 632×240 PAL, 632×186 NTSC (`scr->Height<240` → compact: row pitch 14, list 4 rows). Title `Network Setup`, right-aligned `n / 5` via `WA_ScreenTitle`.
- Left column 110 px: step list (TEXT_KIND ×5). Done = `✓` prefix + `TEXTPEN`, active = `FILLPEN` box with `FILLTEXTPEN`, pending = plain. Drawn with `RectFill` + `Text` in `render_frames()`; refreshed on page change.
- Right pane 494×176 (NTSC 130): recessed bevel (`GTBB_Recessed`). Group frames with titles: `DrawBevelBox` + title text over the top edge on background pen (`RectFill` clear then `Text`).
- Status line 494×12 under the pane (TEXT_KIND, `GTTX_Border`), updated by every async step (probe, scan, associate, tests) from a 1 s `timer.device` tick in the `Wait()` mask — never `Delay()`.
- Button bar: `Cancel` left; `< Back`, `Next >` right; Next/Finish is the default (RETURN), ESC = Cancel, `GT_Underscore` on all; `GA_TabCycle` on string gadgets.

Pages (labels exactly as in the mockup):
1 Replace: LISTVIEW_KIND of detected stacks (name · evidence); checkboxes "Replace them with tolunnet (recommended, non-destructive)" (default on), "Import Roadshow interface settings" (only when found); explanation line.
2 Hardware: LISTVIEW_KIND adapters (`▸` marks selection): friendly name · device · unit · MAC · type/MTU; unusable ones greyed with the S2 error; buttons Rescan, Test adapter (S2_DEVICEQUERY + ONLINE, result in status line).
3 WiFi (wireless only): LISTVIEW_KIND networks: SSID (hidden → `<hidden>`), signal bars `▮▯` 0–5 from `S2INFO_Signal` (dBm: ≥-50=5 … ≤-90=1), channel, security (`S2INFO_Encryption`: open/WEP/WPA/WPA2); Scan button + "2.4 GHz only" hint; Network string (filled from list, editable for hidden), Password string masked (`●`, `Show` checkbox); associate progress with elapsed/30 s in status line; failure text: "Wrong password?" (auth fail) / "Network not found — 2.4 GHz only?".
4 Address: Mode cycle (Automatic (DHCP) / Manual); manual group `GA_Disabled` while DHCP; IP, Netmask, Gateway, DNS 1, DNS 2; Host name, Domain; checkbox "Also write DEVS:Internet/interfaces (Roadshow format) for other tools". Validate on Next with `inet_parse`; error via `EasyRequest`, focus the bad gadget.
5 Test: LISTVIEW_KIND of 5 checks with OK/FAILED + detail + "→ what to do"; buttons "Run tests again" (default until all pass), "Save log…" (ASL file requester → text); checkboxes "Start tolunnet automatically at boot", "Open TolunnetPrefs after finish"; Next becomes Finish.

Proof: bench `tc_wizard_wired` via ARexx port unchanged; add `tc_wizard_ntsc` (open on a 640×200 screen, window fits, no gadget below `scr->Height`); screenshots of all 5 pages PAL+NTSC in the log dir; `docs/iron-test-wizard.md` updated for the WiFi page.

Readability (users 50+, 15" CRT/LCD): default font = screen font (user's Font Prefs); ToolType/config `FONT=name/size` (e.g. `topaz/11`, `xen/11`) via `diskfont.library` `OpenDiskFont`, fallback topaz/8; Prefs gets a "Large text" checkbox writing the same key. Group titles, step names and OK/FAILED words in `FSF_BOLD` (`SetSoftStyle`); no grey hint text — everything in TEXTPEN, hints distinguished by weight only; minimum row pitch = `ta_YSize + 6`; list rows ≥ `ta_YSize + 3`; buttons ≥ 3 chars padding; all layouts re-derive from the chosen font (the mockup is at 13 px ≈ topaz/11).

Additions (v2.1): Address page — DNS 2 (secondary resolver, also used as fallback when the DHCP-supplied DNS fails 3 queries; checkbox "Use DHCP DNS, fall back to DNS 2"), MTU field (576–1500, blank = driver default), "Advanced…" button opening a small requester-window with: task priority, log file, `DATABASE_ORDER`, "Also write Roadshow-style DEVS:Internet files", NTP server + "Set clock at start" (SNTP), IPv6 placeholder (disabled). WiFi page — "Add hidden network…" button (SSID typed, `scan_ssid=1`), up to 4 saved networks with priority order (wpa_supplicant `priority=`), "Forget" button. Test page — "Copy report" (clipboard.device unit 0, IFF FTXT) next to "Save log…". All new keys go through `tolunnet.config` (`DNS2=`, `MTU=`, `NTP=`, `WIFI_PRIORITY=`), none hard-coded.
